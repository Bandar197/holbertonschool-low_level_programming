# C - More malloc, free

This directory contains C functions that demonstrate additional dynamic
memory allocation concepts using malloc, free, and exit.

## Files

- `0-malloc_checked.c`: Allocates memory and exits with status 98 on failure.
- `1-string_nconcat.c`: Concatenates one string with the first n bytes of another.
- `2-calloc.c`: Allocates and initializes an array's memory to zero.
- `3-array_range.c`: Creates an integer array containing a specified range.
- `main.h`: Contains all function prototypes.
