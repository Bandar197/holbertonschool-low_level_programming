# C - malloc, free

This directory contains functions that demonstrate dynamic memory allocation
and deallocation using `malloc` and `free`.

## Files

- `0-create_array.c`: Creates and initializes an array of characters.
- `1-strdup.c`: Creates a dynamically allocated copy of a string.
- `2-str_concat.c`: Concatenates two strings.
- `3-alloc_grid.c`: Allocates and initializes a two-dimensional integer grid.
- `4-free_grid.c`: Frees a two-dimensional integer grid.
- `main.h`: Contains all function prototypes.
