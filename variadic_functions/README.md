# C - Variadic functions

This project covers variadic functions in C.

## Learning objectives

- Understanding variadic functions
- Using `va_start`
- Using `va_arg`
- Using `va_end`
- Understanding the `const` type qualifier

## Files

- `0-sum_them_all.c`: Returns the sum of all parameters
- `1-print_numbers.c`: Prints a variable number of integers
- `2-print_strings.c`: Prints a variable number of strings
- `3-print_all.c`: Prints different argument types according to a format
- `variadic_functions.h`: Function prototypes and data structures
