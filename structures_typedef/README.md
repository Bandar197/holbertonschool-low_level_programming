# C - Structures, typedef

This directory contains exercises about structures and typedef in C.

## Files

- `dog.h`: Defines `struct dog`, `dog_t`, and function prototypes.
- `1-init_dog.c`: Initializes a variable of type `struct dog`.
- `2-print_dog.c`: Prints the contents of a dog structure.
- `4-new_dog.c`: Creates a new dog with copied name and owner strings.
- `5-free_dog.c`: Frees memory allocated for a dog.
